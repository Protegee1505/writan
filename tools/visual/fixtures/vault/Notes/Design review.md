# Design review

Three-pane layout: folders on the left, note list in the middle, editor on
the right. The fixture body is deliberately a few paragraphs long so the
preview pane scrolls and the list shows a real snippet.

## Notes from the last pass

1. Keep the header bar honest: title, search, one primary action.
2. Search should show a snippet with the match, not just the title.
3. Prefer `dim-label` for secondary text over inventing a new colour.

Keywords designers search for: density, contrast, rhythm, spacing.
